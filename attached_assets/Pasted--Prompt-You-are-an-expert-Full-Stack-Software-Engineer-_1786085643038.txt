
# Prompt

You are an expert Full-Stack Software Engineer, UI/UX Designer, and Product Designer.

Your task is to create a **modern, premium, responsive portfolio website** using the resume document that I will upload along with this prompt.

## IMPORTANT INSTRUCTIONS

Do **NOT** hardcode any information about me.

Do **NOT** assume any skills, projects, education, work experience, certifications, contact information, achievements, or personal details.

The uploaded resume is the **single source of truth**.

Every piece of content displayed on the website must first be extracted from the uploaded resume and stored in a structured data model before being rendered.

The website must be generated dynamically from this data model.

If the resume is updated later, only the data model should need updating, while the UI remains unchanged.

# Resume Parsing

Before generating any UI,

extract all information from the uploaded resume.

Organize the extracted information into a structured JSON object.

Every section of the website must consume this JSON object.

No section should directly read the resume.

---

# Data Structure

Create a file:

```
data/portfolioData.ts
```

or

```
data/portfolio.json
```

The extracted data should follow a schema similar to this.

```typescript
export interface PortfolioData {

  personal: {
    fullName: string;
    title: string;
    summary: string;
    profileImage?: string;

    email: string;
    phone: string;
    location: string;

    github?: string;
    linkedin?: string;
    website?: string;
    portfolio?: string;
  };

  skills: {
    languages: string[];
    frameworks: string[];
    libraries: string[];
    databases: string[];
    cloud: string[];
    tools: string[];
    testing: string[];
    technologies: string[];
    operatingSystems: string[];
    other: string[];
  };

  experience: Experience[];

  education: Education[];

  certifications: Certification[];

  projects: Project[];

  achievements: Achievement[];

  publications: Publication[];

  volunteering: Volunteering[];

  awards: Award[];

  languagesKnown: string[];

  interests: string[];

}
```

Create appropriate interfaces for

Experience

Education

Project

Certification

Achievement

Award

Publication

Volunteering

Never hardcode resume content inside React components.

Components must only consume PortfolioData.
